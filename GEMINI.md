# Aturan Operasional (Operational Rules)

1. **JANGAN PERNAH** melakukan `git push` ke GitHub atau server remote manapun, kecuali jika pengguna (*user*) memberikan perintah yang sangat eksplisit seperti "silakan push", "deploy sekarang", atau "commit dan push".
2. **JANGAN PERNAH** menjalankan skrip, melakukan push, atau bahkan **MENYUNTING/MENYIMPAN FILE KODE SECARA LOKAL** tanpa izin eksplisit jika pengguna menyatakan ini adalah sesi "diskusi".
3. Seluruh mode diskusi atau percakapan yang sifatnya eksplorasi harus dijaga murni sebagai diskusi teks (ide/konsep). Semua modifikasi file kode (lokal maupun remote) harus dikonfirmasi terlebih dahulu jika pengguna memberi label "hanya diskusi".
